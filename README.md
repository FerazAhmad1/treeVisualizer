# JSON Tree Visualizer

## 🚀 Features

- ✅ **JSON Visualization** — Renders JSON as an interactive graph.
- 🎨 **Color-coded Nodes** — Different colors for Objects, Arrays, and Primitives.
- 🔍 **Search by JSON Path** — Quickly locate any node by its path.
- ⚙️ **Automatic Layout** — Uses Dagre for clean tree positioning.
- 🧭 **Interactive Controls** — Zoom, pan, and drag nodes.
- 💬 **Toast Notifications** — Get feedback on errors or actions.

# Clone the repository

git clone https://github.com/FerazAhmad1/treeVisualizer.git

# Navigate to the project directory

cd treevisualizer

# Install dependencies

npm install

# Start the development server

npm run dev

## 🧭 How to Use It

1. **Paste or write** your JSON inside the text area on the **left side** of the screen.
2. Click on **“Generate Tree”** — your JSON structure will be visualized as a tree on the **right side**.
3. Use the **search bar** on top to find any node by its JSON path.
   - Your search string **must start with `$`**.
   - **Example:** `$.user.address.city`
